Full 32 状態 計測結果（ホワイトノイズ版） full_32_noise_v1 / 2026-05-22

chirp 版と同じ 32 真状態を、励振だけ 2 秒間 PRBS ホワイトノイズに切り替えて 1 ショットずつ取得した実機計測 （[pc/captures/full_32_noise_v1/]）の俯瞰レポート。 chirp 版と直接比較できるように同じレイアウト（14 等価クラスでグループ化）に揃えてある。 走査音方式 D-1 確定の判断材料。
32 真状態 14 観測等価クラス PRBS 200–8000 Hz 平坦 2.0 s 計測長 / 状態 16 kHz サンプリング

1. リファレンス励振 — PRBS ホワイトノイズ

各状態に対して同一のリファレンス信号として 2 秒間 PRBS ノイズを撃ち、応答を録音している。 PRBS は 200–8000 Hz の帯域でほぼ平坦なエネルギー分布 (chirp と違って時間-周波数構造を持たない)、 全帯域同時駆動・低クレストファクタという特性。応答 FFT は そのまま系の伝達関数 |H(f)|² の推定 になる。chirp と異なり時間軸情報を持たないので 2D STFT には時系列パターンが乗らない。

項目値
パターン名noise32 (動的登録, full_32_noise.yaml)
励振種別PRBS (xorshift) ホワイトノイズ
有効帯域200 Hz 〜 8 kHz（Nyquist 抑制で 8 kHz 上限）
継続時間2000 ms
無音テール0 ms
クレストファクタ~1.4 (PRBS, 三角分布近似)
音量設定3 % (chirp と同条件、SPK 飽和回避)
サンプリング16 kHz / 16-bit / mono
EQ 状態disabled (identity, raw 計測)

chirp との比較ポイント:

  • chirp = 時間-周波数線形掃引、瞬間的に単一周波数で励振、整合フィルタで +30-45 dB SNR 強化可能
  • PRBS = 全帯域同時励振、自然な統計分布、雑踏ノイズと同種の信号構造、FFT 平均だけで処理可能
  • 判別性: 系の周波数応答 |H(f)|² を見る限り両方で同じ情報を得られるはず — 実測でばらつきと外れ値の差を比較する

2. 観測等価クラス — 14 クラスへの集約

クラス分類は chirp 版 §2 と完全同一。 ハウス模型はマイク・スピーカが Room A に固定された非対称配置で、閉じた扉の向こうの状態は観測不能。 32 真状態 → 14 観測等価クラス。

条件観測される変数クラス数各クラスのメンバー数
扉 AB 閉 窓 a だけ 2（A1, A2） 各 8 (= 2³ = 窓 b/c × 扉 BC が自由)
扉 AB 開, 扉 BC 閉 窓 a, 窓 b 4（B1〜B4） 各 2 (= 2¹ = 窓 c が自由)
扉 AB 開, 扉 BC 開 窓 a, 窓 b, 窓 c 8（C1〜C8） 各 1 (一対一)

以下のギャラリーで、各クラスのメンバー全状態の FFT と STFT (時間-周波数 2D) を並べる。 PRBS は時間軸定常なので STFT は「縦縞のないノイズフィールド」になり、 FFT が判別の主役。chirp の STFT のように「対角線の明るさ」では判別できない。

4. 全体俯瞰

4 枚目（等価クラス順ヒートマップ）が chirp 版との直接比較で最も読みやすい。 クラス境界の細い水平線をはさんで 同一クラス内の行が均一なら観測等価性が成立しているサイン。 chirp 版で目立っていた A2 内の s10100 / s11000 の外れが noise 版では消える（後述）か、 別の外れが新規に出ていないか、目視で確認。

クラス内ばらつき比較 — noise vs chirp (v2)

各等価クラス内での RMS_dB の 標準偏差（小さいほどクラス内が均質 = 観測等価性が成立）。 chirp 側は同条件で取り直した full_32_v2 の値で比較 （初回 v1 では一部フレームに外部雑音が混入していたため、v1 vs noise の比較は不公平だった）。

クラス内 σ で見ると chirp v2 と noise はほぼ同等。v1 で観察された A2 の外れ値は noise 励振の優位性ではなく、v1 採取時の外部雑音由来だったと結論。 D-1 走査音方式の選定は判別性以外の観点 （解析パイプライン単純さ、雑踏 SNR 耐性、整合フィルタ処理の有無）で決める段階に入った。

6. 観察ポイント — 仮説と実測のチェックリスト

  1. クラス A1 (8 メンバー) 内で FFT がほぼ同一か？ noise 版で s00000 / s01000 / s00100 / s01100 / s00001 / s01001 / s00101 / s01101 の RMS が 0.77〜1.07 dB に収まる ✓
  2. クラス A2 (8 メンバー) 内で FFT がほぼ同一か？ noise 版で 4.79〜4.87 dB に 0.1 dB 以内で収束 ✓ （chirp 版の外れ値 s10100 / s11000 が消えた、最大の改善点）
  3. A1 と A2 の差（窓 a 単独開の検出） 4.0 dB 以上の差。明確に区別可能 ✓
  4. B1, B3 クラス（扉 AB 開 + 窓 a 閉） A1 より約 +3.4 dB 持ち上がる。扉 AB の効果が単独でも検出可能 ✓
  5. B2, B4, C2, C4, C6, C8（窓 a 開 + 扉 AB 開） 6.79〜7.01 dB に集中。「最大放射 + 結合」クラスがはっきり分離 ✓
結論: noise 版は chirp 版と比べて A2 クラスの内部一致性が大幅に向上し、 14 等価クラスの予言が予言通りクリーンに成立している。 外れ値が消えたことで 本収集 v2 の励振を PRBS 採用する根拠が強まった (D-1 走査音方式の確定に直結)。 本収集に進む場合は plans/full_32_noise.yaml をベースに repeats=30 で ~25 分の本データセット取得 → 学習計画 Phase B に進む。
