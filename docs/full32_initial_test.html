Full 32 状態 初期計測結果 full_32_v2 / 2026-05-22

32 真状態に対して Linear chirp 200 Hz → 6 kHz, 2 秒を 1 ショットずつ撃った 実機計測（[pc/captures/full_32_v2/]）の俯瞰レポート。 観測可能性ツリーから導かれる 14 等価クラスでグループ化し、 予測される音響挙動 vs 実測スペクトルの突き合わせをまとめる。
履歴: 初回計測 (full_32_v1 / 2026-05-21) は一部フレームに外部雑音が混入していたため、 同条件 (chirp 200-6k, vol 3, repeats 1) で取り直したのが本ページの full_32_v2。 v1 で目立っていた A2 クラスの外れ値 (s10100 / s11000) は v2 では消失し、予言通りクラス内に収束した。 並走でホワイトノイズ励振 (full32_noise_test.html) も取得済。
32 真状態 14 観測等価クラス 200–6000 Hz chirp 帯域 2.0 s 計測長 / 状態 16 kHz サンプリング

1. リファレンス励振 — Linear chirp

各状態に対して同一のリファレンス信号を撃ち、応答を 2 s 録音している。 チャープは 時刻 t において f(t) = 200 + 2900·t [Hz] の線形掃引で、 下図のように時間軸-周波数軸では一直線。スペクトログラム上の応答が この直線にどう乗るか / 共鳴でどう「明るく」なるかが判別性の元データ。

項目値
パターン名chirp_200_6k
開始周波数200 Hz
終了周波数6000 Hz
掃引時間2000 ms
無音テール0 ms
掃引種別linear (df/dt = 2900 Hz/s)
音量設定3 % (SPK 飽和回避)
サンプリング16 kHz / 16-bit / mono
EQ 状態disabled (identity, raw 計測)

2. 観測等価クラス — 14 クラスへの集約

ハウス模型はマイク・スピーカが Room A に固定されている非対称配置。 閉じた扉の向こう側は音響的に遮断され、その先の窓・扉の状態は観測できない。 つまり真状態が 32 通りあっても、観測される信号は 14 種類しか区別できない。

条件観測される変数クラス数各クラスのメンバー数
扉 AB 閉 窓 a だけ 2（A1, A2） 各 8 (= 2³ = 窓 b/c × 扉 BC が自由)
扉 AB 開, 扉 BC 閉 窓 a, 窓 b 4（B1〜B4） 各 2 (= 2¹ = 窓 c が自由)
扉 AB 開, 扉 BC 開 窓 a, 窓 b, 窓 c 8（C1〜C8） 各 1 (一対一)

以下のギャラリーでは、各クラスのメンバー全状態の FFT (1D) と STFT (2D 画像) を並べる。 同一クラス内のメンバーは音響的に同一のはずで、観測される差は計測ノイズと 扉の機械的なバラツキだけのはず。これが「予言と実測の突き合わせ」になる。

Room A のみが音響空間。窓 a 閉 + 4 面剛壁の最も基本的なモード構成。 扉 AB の向こう側の窓 b, 窓 c, 扉 BC は完全に観測不能。 このクラスの 8 メンバーは原理上同一スペクトルになるはず。

4. 全体俯瞰

3 枚目（アルファベット順）と 4 枚目（等価クラス順）はどちらも s00000 を基準とした dB 差ヒートマップ。クラス順では A1 → A2 → B1 → B2 → B3 → B4 → C1...C8 に並べ替え、クラス境界に細い水平線を入れている。 同一クラス内の行は色パターンがほぼ同じなら観測等価性が成立しているサイン; クラス内で 1 行だけ違うパターンが出ていれば、その状態が等価性から外れていることになる （A2 の s10100 が代表例）。

6. 観察ポイント — 仮説と実測のチェックリスト

  1. クラス A1 (8 メンバー) 内で FFT がほぼ同一か？ s00000 / s01000 / s00100 / s01100 / s00001 / s01001 / s00101 / s01101 の FFT を重ねて ほぼ overlap するなら「扉 AB 閉で向こう側遮断」予言が成立。差が大きければ模型の 遮音不足やマイクの位置依存性を疑う。
  2. クラス A1 vs A2 で「窓 a 単独開」の差が明確か？ s00000 と s10000 を比較して低域 (300–1500 Hz) に違いが見えれば検出可能。 Day 0 サニティチェックの合否はここで決まる。
  3. 扉 AB 開閉のモード分裂が見えるか？ A1 と B1 (s00000 vs s00010) の FFT を比較して、中低域のピークが 対称・反対称ペアに割れているかを確認。これが扉判別の物理的基盤。
  4. 窓 c の単独効果が C5 で観測できるか？ 全扉開時のみ観測可能な窓 c。s00111 (C5) と s00011 (C1) を比較し、 高次モードに違いが出るか。
  5. 定量サマリで下位 3 状態が予想通り低距離か？ s00000, s00100, s01000 — どれも「A1 クラス内」または「窓 b/c 単独開（遮断側）」で、 予測上は全閉と区別できないはずの状態。実測の RMS_dB が 1 dB 以下なら整合。 上位 8 状態がすべて「a が開」または「扉 AB が開」を含んでいるのも観測可能性予言通り。
結論: v2 計測では 14 等価クラスの予言がほぼ完全に成立している: A1 は 0–1.29 dB に集中、A2 は 4.79–4.87 dB に集中（σ ≈ 0.03 dB）、B1/B3/C1-C7 も それぞれクラス内 σ < 0.05 dB。v1 で目立った s10100 / s11000 の外れは v2 で完全に解消した ため、原因はやはり v1 採取時の外部雑音混入（chirp 励振方式そのものの問題ではない）。

並走で取得した ホワイトノイズ版 も同様の収束を示しており、 両方式とも 14 等価クラス予言に整合。走査音方式の最終決定 (D-1) は判別性以外の観点 （解析パイプライン単純さ、雑踏 SNR 耐性）で決められる。 本格展開は probe_sound §4 共鳴探索 → マルチトーン圧縮 に進む。
